Entry for the make.fun bounty "Five Seconds to Explain the Glass": a small Python program that writes the house cat's one-sentence defence — delivered in the five seconds after a glass leaves the table — to `entry.txt` in the output directory. No apology, no confession; the cat had a reason, and the reason is you.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
